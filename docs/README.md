# Akochan ドキュメント案内

このディレクトリは、Akochan を「対局イベントを局面へ変換し、候補行動を順位点の期待値で比較する仕組み」として学ぶための入口です。最初の一読では概念と処理のつながりを追い、実装を確認するときだけ各文書末尾の「実装対応」を開いてください。

ファイル名、関数名、設定キー、MJAI のイベント名は、実装や外部プロトコルを特定するための参照語です。名前そのものをアルゴリズムの定義とは扱いません。

## 入力から行動までの短い地図

```text
MJAI / 自己対局のイベント列
  → 最新の start_kyoku から局面を復元（02）
  → 待ち・役・符と合法な候補を作る（02, 03）
  → 他家の聴牌・待ち・打点を推定する（04）
  → 和了・放銃・流局を点数と順位点へ変換する（03, 04）
  → pt_exp_total で候補を比較する（03）
  → MJAI の 1 または 2 イベントとして返す（03, 05）
```

| 段階 | 主な責務 | 詳細 |
|---|---|---|
| イベント入力 | MJAI のイベント列を受け取る | [05](./05-runtime-and-mjai.md) |
| 局面復元・ルール判定 | 手牌、河、待ち、役、符、合法手を得る | [02](./02-state-rules-scoring.md) |
| 候補生成・探索 | 打牌、リーチ、鳴き、槓、和了、パスを比較する | [03](./03-ai-search-and-decision.md) |
| 未知情報の推定 | 他家の聴牌・待ち・打点・局終了を確率化する | [04](./04-models-evaluation-and-parameters.md) |
| 将来価値・出力 | 順位点期待値を作り、最良候補を出力する | [03](./03-ai-search-and-decision.md)、[05](./05-runtime-and-mjai.md) |

## 用語

| 用語 | 意味 |
|---|---|
| MJAI | 対局サーバーとプレイヤーが交換する JSON イベント形式 |
| イベント列 | 局の開始、ツモ、打牌、鳴き、和了、流局などを時系列に並べた記録 |
| 局面 | イベント列を再生して得られる、4人の手牌・副露・河・立直状態・点数など |
| 牌種 | 赤牌を通常牌と同じ牌として扱うときの種類。赤牌の有無は別情報として残る |
| 副露 | チー、ポン、明槓、暗槓、加槓によって公開された面子 |
| シャンテン | 和了までの距離。共有ルール層と探索層で定義が異なる場合がある |
| 待ち | 1枚加えることで和了形を完成できる牌種と、その形（両面など） |
| 順位点 | 局後の点数から順位へ変換した評価単位。既定値は 1 着90、2着30、3着-30、4着-90 |
| 候補グラフ | 手牌状態を頂点、ツモ・打牌・鳴き・槓などの遷移を辺とする探索表現 |
| DP | 残りのツモ回数を基準に、終端価値から現在へ期待値を戻す計算法 |
| `pt_exp_total` | 候補行動の局後順位点期待値。最終比較の軸 |

## 読み方と実装の境界

各詳細文書は、概念の説明 → 現行実装の境界 → 実装対応、の順に分けています。最初の一周では「実装上の境界」を飛ばして流れをつかみ、二周目に標準ルールや一般的な確率モデルと異なる箇所だけ確認すると効率的です。

本文の数式は、確率の合成、期待値、牌の残数などを表す記法であり、特定の言語の文法やデータ構造を示すものではありません。現行実装に固有の制約（複数ロンの精算、和了直後の点数反映、モデルの近似、入力検証の弱い箇所など）は各文書に分離して記載しています。

各文書末尾の「実装対応」には、概念を確認できるソースファイルと関数をまとめています。行番号は変更でずれるため、リンク先では関数名も併せて検索してください。

## 対象外

- ビルド手順は [`akochan/readme_jpn.md`](../akochan/readme_jpn.md)（日本語）または [`akochan/readme.md`](../akochan/readme.md)（英語）にまとめ、05 では判断コアと実行アダプタの構成だけを説明します。英語版には自己対局の補足もあります。
- 固定重みの学習データ、学習手順、精度指標はリポジトリに含まれないため、04 では推論時の利用だけを扱います。
- JSON パーサーなどの汎用ライブラリの内部実装は扱いません。

`akochan/readme_jpn.md` と `akochan/readme.md` は Linux・Windows の依存ライブラリ確認とビルド手順を記した利用者向け upstream README です。upstream README は本再構成の対象外とし、内容を変更しません。概念解説には統合せず、実行前の補助資料として扱います。
